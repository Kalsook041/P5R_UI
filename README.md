# PHANTOM UI · 怪盗界面实验室

一个可实时调整与复制代码的 P5R UI 组件网站。v2 按用户“与原版不像”的反馈修正：标题和暂停菜单默认直接运行认可留档的原资源复刻；网站改为原暂停场景、拼贴字形与斜切纸片构图。原生 HTML / CSS / JavaScript，零第三方运行依赖，新增代码为 MIT，游戏素材保留原权利。

## 原版复刻与文字适配

标题和暂停菜单有两种模式，设置分别保存：

- **原版复刻（默认）**：原字形、专属衬底、测量曲线、混色/遮罩、场景底图。可调整摆幅、周期、选中缩放、倾角与速度；字形图像里的文字固定。
- **文字适配**：用可编辑的拼贴字形网页实现，可自由改菜单文字、字号、颜色等；此模式不声明与原素材相同。

其他五个原创组件与地点纸片适配继续保留，并在站内标明来源。原版导出已内嵌全部图片与测量数据，仍可单文件运行；代码窗折叠资源数据以便阅读，复制/下载保留完整内容。

## 运行

在本目录打开终端：

```powershell
python serve.py
```

打开 <http://127.0.0.1:18770/>。也可使用 `python serve.py --port 18800`。运行站点不需要 Node / npm，不能直接双击主站的 index.html（ES module 需要 HTTP）；下载的独立示例可以双击运行。

## 在线网站

GitHub Pages 部署地址：<https://kalsook041.github.io/P5R_UI/>。推送到 `main` 后，GitHub Actions 会把 `dist/` 发布到 Pages；也可以在仓库的 Actions 页面手动运行 `Deploy to GitHub Pages`。

## 组件

| 效果 | 实现依据 | 可调内容 |
| --- | --- | --- |
| 标题菜单 | 认可 V3 双底片四阶周期、进入/退出缩放及倾角曲线 | 菜单文字、字号、倾角、摆幅、缩放 |
| 暂停菜单 | 研究中的文字/纸片/碎片分层，标题曲线转译 | 文字、字号、倾角、缩放 |
| 地点选择 | 75 ms 进入、55 ms 退出的纸片拟合，支持中断续接 | 地点文字、字号、伸展、文字位移 |
| 怪盗对话框 | 原创风格扩展 | 角色名、对白、字号、逐字速度、倾角 |
| 怪盗预告信 | 原创风格扩展 | 标题、收件人、正文、字号、倾角 |
| 撕裂式切入 | 原创风格扩展 | 标题、副标题、字号、倾角、裂片间距 |
| 星芒转场 | 原创风格扩展 | 文字、字号、星芒数量、倾角 |
| 能力数值条 | 原创风格扩展 | 面板标题、能力名称、5 项数值、字号 |

所有组件支持暂停、重播、0.25×—2× 速度与预览背景切换；文字适配与原创组件支持强调色。当前浏览器保存每个效果和模式的参数；重置仅影响当前效果/模式。菜单支持鼠标、触屏和方向键 / Home / End；`/` 聚焦搜索。

## 复制与导出

“完整示例”含 HTML、CSS、JS、当前参数和 MIT 许可，可以保存成 `.html` 文件直接运行。HTML / CSS / JS 标签可单独复制对应片段；单独片段需组合使用，JS 放在元素之后。剪贴板写入失败时提供可手动选择复制的文本框。

下载文件无需网络、服务器或额外游戏资源文件。`dist/examples/` 提供 8 个文字适配/原创示例及 `original-title.html`、`original-pause.html` 两个原版复刻。预览和导出由同一个生成器产生；浅色/深色背景按钮是预览工具，独立导出默认使用场景。

独立示例采用整页样式。多个效果嵌入同一业务页面时，建议使用 iframe 隔离，或自行为样式和 DOM 查询添加作用域。

```powershell

```

测试覆盖完整导出可解析、参数进入导出、恶意文本转义、研究系数有效、菜单条目边界和损坏持久化设置回退。浏览器结果见 `VERIFICATION.md`，复查与修复提示词见 `REVIEW_PROMPTS.md`。

## 文件

- `dist/index.html` / `style.css`：网站布局与视觉。
- `dist/app.js`：目录、参数面板、持久化、预览控制、代码复制及下载。
- `dist/effects.js`：效果目录、参数约束、完整导出生成器及独立运行器。
- `dist/research-model.js`：文字适配使用的 V3 观测拟合数据。
- `dist/originals.js` / `original-data.js`：原版运行器、认可版源码、完整测量模型与内嵌素材。
- `dist/royal.css` / `art/command.jpg`：v2 页面视觉及原暂停菜单场景图。
- `tools/build-originals.mjs`：从工作区认可留档重新生成原版数据；日常使用已生成文件，不需要重新构建。
- `dist/SOURCES.md` / `LICENSE`：来源边界与许可。
- `serve.py`：仅绑定本机的静态服务器。

研究拟合不是游戏引擎常量。原版模式和主视觉使用本地研究包的游戏字形、贴图与场景图，这些不属于 MIT 许可。本站不包含视频或音频；对话框等五项扩展不是逐像素还原。原始研究和认可留档保持原样。最新验证见 `ROYAL_REVISION.md`。
